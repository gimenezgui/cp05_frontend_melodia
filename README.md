# Melodia 

Landing page desenvolvida para apresentar o aplicativo fictício de músicas **Melodia**, como parte do Checkpoint 05 de Front-end da FIAP.

## Sobre o projeto

A página apresenta os benefícios e as funcionalidades do aplicativo, depoimentos de usuários e um formulário para demonstrar o cadastro de interessados em receber novidades.

> O formulário é demonstrativo: ao enviar, ele exibe uma mensagem de confirmação e limpa os campos. Os dados não são enviados nem armazenados.

## Tecnologias utilizadas

- HTML5
- Tailwind CSS
- JavaScript
- Font Awesome
- Google Fonts

## Funcionalidades da página

- Menu responsivo para dispositivos móveis
- Navbar com efeito visual ao rolar a página
- Navegação entre as seções
- Formulário demonstrativo com validação dos campos
